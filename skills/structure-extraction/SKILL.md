# 论文结构拆解框架（L1 薄壳）

## 定位与边界

本文件是**静态壳**：只放不随拆解演化的内容（红线、流程、栏定义、输出契约）。任何会演化的清单（类型库、标签库、评分指引、维度清单、锚点）**禁止写入本文件**，执行任务时从结构库读取。

- 结构库根：由插件设置页的 libraryPath 指定；未配置时任务先提示配置，不要臆造路径。
- 拆解任务输入五件：`类型库.md` 快照、`标签库.md` 快照、`评分指引.md`、`维度清单.md`、`锚点样本/` 相关条目
- 单篇输出格式：`篇目/_模板.md`（字段变动先改 schema 定义，再改模板）

## 红线（违反任何一条即返工）

1. **不预设类型清单**。底座可以固定"一条描述必须登记哪些维度"（语法层），但"片段有哪些类型"的答案不得提前写死。预设类型清单与预设五节骨架性质相同。
2. **拆解必须是模型智能理解**。理解段自由深读、判断、追问；禁止机械切块。套话进标签库会隐蔽地污染聚类。
3. **任务派分**：语义任务（功能、对齐、类型判断）给智能理解；边界与计数任务（切分、粒度计数）找物理锚点，不交语义判断——切错是静默错误。
4. **可追溯**：每个判断挂位置（`§x.y` 或 `¶n` 多级编号）+ 附原文引文；回溯不到的标"待核"，宁缺勿伪。
5. **两轴分开**：置信度与评分不压单一数值。
6. **裁决权归用户**：新类型宣告、标签合并、维度复核、切分结果，模型一律提案不拍板（文献否决权）。

## 流程（六步）

1. **篇级边界判定（事实判据，不交语义判断）**：查标题页、作者署名、目录、出版信息。单篇论文/卷章判定即结束；判定为合集才切，切点对齐各自标题与署名，**不向节下探**（节无独立署名与标题页）；切分结果交用户复核。
2. **理解段（自由）**：通读深读。核心论题、论证骨架、反对意见处理、理论资源用法、隐含前提、首尾策略——描述可丰富、贴原文。
3. **落格段（受约束）**：登记通用薄层五栏 + 涌现字段，全部挂位置、附引文。理解段的每个重要判断都要能在落格段找到对应位置与引文，这是智能理解的验收口。
4. **打标**：先比对 `标签库.md` 做语义查重，相同即复用不新造；确属新标签才写入，回填首次出现篇目。
5. **新类型宣告**：拿 `类型库.md` 快照比对——能匹配既有类型则复用；确属新类型才宣告（候选名/定义/依据/引文），状态记"候选"，等用户裁决。
6. **评分与元信息**：按 `评分指引.md` 打三层分数（篇/节点/片段，三层独立不派生）；节点级只给有功能标注的节点打；锚点无条目标"无锚点参照"。回填元信息全部字段，含低可拆解度判定。

## 通用薄层五栏（栏目固定，内容全涌现）

| 栏 | 定义 | 常见错误 |
|---|---|---|
| 位置 | 片段坐标，多级编号（`§2.1.3` 或 `¶4`） | 只写"第二节"——无法回溯到段 |
| 处置动作 | 该片段在做什么（动词性描述，涌现） | 用预设类型名填动作 |
| 对象 | 动作指向什么（内容/他人论点/概念/文本） | 与动作混写 |
| 依据 | 原文引文，原样摘录 | 用自己的转述冒充引文 |
| 目的 | 该片段在全篇论证中的作用 | 只复述内容不写作用 |

论证与阐释一视同仁；一段多功能则分多行登记，各功能各挂各的位置。

## 三层结构

- **通用薄层**：上述五栏，适用于任何文本片段。
- **类型层**：由片段级"处置动作"归并而来，判定落在段落级，跨篇累积于类型库。
- **子语法层**：每个类型长自己的深挖语法；论证型挂"前提→结论"或 Toulmin 六件套（claim/grounds/warrant/backing/qualifier/rebuttal），是**可挂载分支**，不预置给其他类型。

## 低可拆解度出口

阐释说明型文本可拆解度天然低。硬拆会产出垃圾，垃圾进标签库污染聚类——判定为低可拆解度时，**只存元信息，理解段与落格段留空**，元信息勾选该标记。

## 写作取用（取用通道一）

用户在对话里说要写某部分、找规律、找范例，或给出现稿求改时：

1. **检索**：调 `paper-structure-modeling_search_structure`（query 用写作主题与结构意图的关键词，空格分隔）；也可直接读 `结构库/写作模型/` 与 `篇目/` 目录。命中排序是物理层，只负责收窄候选。
2. **筛选**：语义判断哪些规律与当前写作意图相关——这一步归你，不归关键词。
3. **交付**：给出规律与范例时**每条挂出处**：写作模型的类型与条目位置，连同其证据实例的原篇目位置与原文引文（实例是骨架的证据）。回溯不到的不给，宁可说“库里暂无对应规律”。
4. **边界**：取用是建议，写作判断归用户。库为空或无命中时直说，不编造规律。

## 输出契约

- 落盘：`结构库/篇目/<id>.md`，`<id>` = `<作者slug>-<年份>`（如 `sample-2020`）。
- 内容 = 理解段 + 落格段 + 新标签（回写标签库）+（若有）新类型宣告 + 三层评分 + 元信息。
- 若有新类型宣告或标签复核队列变更，随拆解任务显式列出，不静默写库。
- 篇目写定即稳定；修订须在该篇元信息追加修订记录。
