# 结构库（L2 数据层）

> 设计依据：存储落点、单篇 schema、三层结构与两段式、闭包归一、评分体系。
> 读写方：插件（`ctx.resources`）与库主（直接打开、grep）。全部 markdown。
> 本 README 即结构库的接口契约；字段有变动先改 schema 定义，再同步此处与模板。

## 目录约定

| 路径 | 内容 | 写入方 | 演化规则 |
|---|---|---|---|
| `篇目/<id>.md` | 单篇拆解记录 | 拆解任务（A 路径助手 / C 路径插件 session） | 写定即稳定；修订须记入该篇拆解元数据 |
| `篇目/_模板.md` | 单篇 schema 模板 | 随 schema 定义演化 | 改模板不改存量；存量按原模板解读 |
| `标签库.md` | 涌现标签累积表 | 打标环节 | 只累积不删；归并动作走闭包映射表 |
| `类型库.md` | 归并后的当前类型 | 标签归并三道 | 每轮演化后压平闭包 |
| `闭包映射表.md` | 原始类型 → 当前类型（单跳）+ 演化日志 | 归一机制 | 只改右值不追加行 |
| `锚点样本/` | 库主打分的锚点记录 | 库主（或助手代录，署名库主） | 只增 |
| `评分指引.md` | 按类型分组的打分指引 | 锚点归纳 | 库主复核后整体替换，留版本痕迹 |
| `维度清单.md` | 按类型分组的评分维度 | 高低分归纳 | 涌现 + 库主否决权 |
| `写作模型/` | 生成的模型产物 | 建模环节 | 版本化，不覆盖历史 |

## 拆解任务的输入 / 输出

- **输入** = L1 拆解框架（薄壳 skill）+ `类型库.md` 快照 + `标签库.md` 快照 + `评分指引.md` + 锚点样本相关条目。
- **输出** = 理解段 + 落格段 +（若有）新类型宣告 → 落 `篇目/<id>.md`；新标签进 `标签库.md`。

## 不变量（硬约束）

1. 位置栏必须多级编号（`§x.y` 或 `¶n`），判断必须附原文引文——可追溯总则。
2. 记录存原始类型，打上即定不改；类型演化一律走闭包映射表，永远单跳。
3. 两轴分开存：置信度（样本量/频率/锚点覆盖）与评分不压单一数值。
4. 理解段自由、落格段受约束；归一化只作用于落格段。
5. 篇级边界判定用发表物边界事实判据，切分结果交库主复核。
