# 锚点样本

> 机制（§5.5，库主第 21、23 轮）：库主打一批篇级总分（10-20 篇，覆盖各类型），只增不改。三层分数最终全部自动打，锚点是标准注入的源头。
> 两个用途（严格限定）：
> 1. **归纳**：从分数与理由提炼 `../评分指引.md`（按类型分组），随拆解任务下发。
> 2. **盲打校验**：模型不看库主的分数打锚点，比对偏差；超阈修指引再验。模型见过分数则检验失效。
> 不做逐篇相似度匹配（库主第 22 轮否掉）。

## 记录格式：每份一个文件 `<篇目id>.锚点.md`

```markdown
# 锚点：<篇目标题>

- 对应篇目：篇目/<id>.md（若未拆解，记出处与文件位置）
- 文本类型（库主判）：
- 库主打的篇级总分：
- 理由（该文好/差在哪，尽量具体）：
- 打分日期：
- 录入：库主 / 助手代录（库主口述）
```
