# 闭包归一映射表

> 机制（§4.2，库主第 37 轮定案）：
> 1. 记录存**原始类型**，打上即定、永不改——本表左列即全库原始类型全集。
> 2. 右列为**当前类型**，表内永远单跳：查询原始类型 →（一跳）→ 当前类型。
> 3. 每轮演化后**压平闭包**：只改写已有行的右值，不追加行。行数 = 出现过的原始类型数，与演化轮次无关。
> 4. 压平后仍为多对多的，唯一归属进复核队列由库主裁决钉死；钉死值跟随其类型后续走映射，仍为单跳。
> 5. 三版被否留档：追加式 / 双字段批处理 / 标签分组视图（理由见设计文档 §4.2）。
